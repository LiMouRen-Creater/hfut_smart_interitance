记录智能车竞赛的方案迭代、实车调试与赛季经验，供后续队员学习，并按赛季持续补充。

## 阅读入口

**[打开《智能车传承文档》](./智能车传承.md)**

文档包括历届比赛概述、核心任务方案与技术迭代、问题排查与实车经验、开发工作流与版本管理、快速入门五个章节。

配套图片位于 [传承文件对应说明图片](./传承文件对应说明图片/) 目录。

## 维护约定

- 更新前先读取最新版本，保留其他队员的修改。
- 按赛季追加经验，区分已验证结论与待验证建议。
- 图片使用仓库内相对路径，修改后检查链接是否有效。
- 本仓库仅存放文档与配套图片，不包含比赛源码、模型、数据集和 API 密钥。
